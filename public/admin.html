NAS / Docker configuration
  1. Connect a download source. In the server’s .env, set REAL_DEBRID_TOKEN or PREMIUMIZE_API_KEY. A configured token still needs a valid account and subscription.
  2. Choose storage. Set DATA_DIR and MEDIA_DIR to folders on the NAS. Set CACHE_BUDGET_BYTES to the space available for cached files. Old files are removed when the cache reaches its budget.
  3. Configure the encoder. Set TRANSCODE=true. Use TRANSCODE_HWACCEL=qsv for Intel Quick Sync with a tested VAAPI fallback, or vaapi to select VAAPI directly. Pass /dev/dri into the container and set VIDEO_GID / RENDER_GID to its device group IDs. TRANSCODE_DEVICE defaults to /dev/dri/renderD128. Software encoding uses TRANSCODE_HWACCEL=none; remove the device and GPU group entries from Compose if the host has no GPU.
  4. Apply and verify. From the Mediawan directory on the server, run the commands below, then refresh this page. 
    docker compose up -d
docker compose exec web node scripts/check-pipeline.mjs

Set PUID and PGID to a NAS user with write access to both folders. The full Compose stack also requires SEANIME_PASSWORD and TUNNEL_TOKEN. See the NAS setup section in README.md.
